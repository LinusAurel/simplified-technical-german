Das System soll Anfragen zeitnah beantworten.
Wenn ein Fehler oder eine Zeitüberschreitung auftritt, soll das System eine Meldung im Protokoll ausgeben.
Hinweis: „zeitnah“ ist nicht messbar und „soll“ legt nicht fest, ob eine Pflicht gemeint ist. Nennen Sie eine maximale Antwortzeit und die beabsichtigte Modalität.
