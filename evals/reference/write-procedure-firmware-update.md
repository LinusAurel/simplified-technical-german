1. Laden Sie die Datei fw-2.4.1.bin herunter.
2. Öffnen Sie die Weboberfläche des Gateways GW-200.
3. Öffnen Sie das Menü „System > Update“.
4. Wählen Sie die Datei fw-2.4.1.bin aus.
5. Klicken Sie auf „Installieren“.
6. Trennen Sie das Gateway nicht von der Stromversorgung, bis die LED STATUS grün leuchtet. Das Update dauert ungefähr 3 Minuten.
